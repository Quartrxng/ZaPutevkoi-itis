### Как запускать

Далее либо:-------------------------------------------------------------------------------------------------------------------------

  1.1 Создать БД в PostgreSQL и использовать /tables/init.sql для заполнения БД
  1.2 Запустить приложение в IDE, перед этим настроив в settings.json:
                  1)строку подключения к БД
                  2)порт и домен приложения (по умолчанию http://localhost:1337/)
  1.3 Зайти на сайт в браузере. http://домен:порт/

Либо:-------------------------------------------------------------------------------------------------------------------------------

  2.1 Скачать Docker Desktop и настроить под Linux
  2.2 Поменять домен приложения на +, а Host в строке подключения к БД на postgres.
  2.2 Ввести команду docker build -t (НАЗВАНИЕ - по умолчанию try14) -f MiniHttpServer/Dockerfile .
  2.3 Если указали другое название, то в docker-compose.yml поменять app -> image на ваше название
  2.4 Если меняли порт, то в docker-compose.yml поменять все порты (1337) на ваш порт
  2.5 Поменять все данные БД на свои в docker-compose.yml
  2.5 Ввести команду docker-compose up -d (Если далее нужно будет привести БД к первоначальному виду, то перед запуском писать               docker-compose down -v)
  2.6 Перейти на сайт. Чтобы остановить приложение нужно написать команду docker-compose down

## Настройка базы данных

Если возникли проблемы с подключением к базе данных, измените строку подключения (connection string) в файле конфигурации:

### Расположение файла конфигурации:
- `settings.json` 

### Пример строки подключения:
{
  "PublicDirectoryPath": "public",
  "Domain": "Если postgress, то +, иначе localhost",
  "Port": "1337",
  "Sql": "Host=localhost;Port=5432;Database=HttpServer;Username=postgres;Password=YOUR_DB_PASSWORD"
}
